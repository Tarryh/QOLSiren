# Siren

**IF** you have **Tampermonkey** **OR** on **IOS** download Extension.js:
**IF** you **DONT** have **Tampermonkey**, download Extension.zip

Features: 
- Offline Reader
- Comick Importer
- Offset Page
- Auto set to Reading
- Quick Apply to List
- Quick Mark Chapters as Read


The ZIP file contains all of the data above zipped, the Extension.js file is among them
